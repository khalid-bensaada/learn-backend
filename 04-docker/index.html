04 / CONTAINERS

Docker.

Package the backend and run it alongside MongoDB in a reproducible environment.

Why Docker?

A Docker image contains the application and its runtime setup. A container is a running instance of an image.

Docker Compose describes multiple services and connects them using a private network.

Your Dockerfile

FROM node:22-alpine

WORKDIR /app

COPY package*.json ./
RUN npm install --omit=dev

COPY . .

ENV PORT=3000
EXPOSE 3000

CMD ["npm", "start"]

This builds the Node.js app image. MongoDB will use its own official image, defined in docker-compose.yml.

Start the containers

docker compose up --build

Compose builds the application, starts MongoDB and then starts the app after the database health check passes.

Important detail

Inside Compose, the app connects to mongodb://mongo:27017/learn_backend. The hostname mongo is the database service name.

What connects next?
