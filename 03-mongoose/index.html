03 / DATABASE

Mongoose.

Define your document structure, validate data and communicate with MongoDB through JavaScript models.

Schema versus model

A schema defines the fields and validation rules for documents. A model gives you methods to create and query documents.

MongoDB stores the data. Mongoose provides the application-facing interface to that data.

Create a Note model

const mongoose = require("mongoose");

const noteSchema = new mongoose.Schema({
  title: {
    type: String,
    required: true,
    trim: true
  },
  body: {
    type: String,
    default: ""
  }
}, { timestamps: true });

const Note = mongoose.model("Note", noteSchema);

module.exports = Note;

The title is required. Timestamps add createdAt and updatedAt fields automatically.

Connect to MongoDB

await mongoose.connect(
  process.env.MONGODB_URI
);

const note = await Note.create({
  title: "My first note",
  body: "Learning backend"
});

console.log(note);

The database URI comes from an environment variable rather than being hard-coded throughout your application.

What connects next?

The application needs MongoDB to be available. Docker Compose can run both the backend and database in a shared network.
