Node.js.

JavaScript beyond the browser. Node.js runs server-side code, provides built-in modules and keeps your application running.

What is Node.js?

Node.js is a JavaScript runtime built on the V8 engine. It provides APIs for networking, files and other system tasks.

Important concepts

  • Modules organize code into reusable files.
  • The event loop coordinates asynchronous operations.
  • npm installs and manages project packages.

Your first Node.js server

const http = require("node:http");

const server = http.createServer((req, res) => {
  res.writeHead(200, {
    "Content-Type": "text/plain"
  });

  res.end("Hello from Node.js!");
});

server.listen(3000, () => {
  console.log("Server running on port 3000");
});

Save this example as hello.js, then run node hello.js. Open localhost port 3000.

What connects next?

Node.js can create an HTTP server directly. Express builds on Node.js and makes routing and middleware easier to manage.

REMEMBER

Node.js is not a framework.

It is the runtime that executes your JavaScript backend.
