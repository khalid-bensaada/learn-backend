Express.js.

Build HTTP APIs with routes, middleware and structured responses. Express runs inside your Node.js application.

How Express works

A request enters the Express app. Middleware can process it, a route handler performs the requested operation, and a response is sent back to the client.

Key terms

  • app.get() handles GET requests.
  • app.post() handles POST requests.
  • req describes the incoming request.
  • res sends a response to the client.

A small Express API

const express = require("express");
const app = express();

app.use(express.json());

app.get("/api/hello", (req, res) => {
  res.json({
    message: "Hello from Express"
  });
});

app.listen(3000, () => {
  console.log("API started");
});

The JSON middleware parses JSON request bodies. The GET route returns a JSON response.

What connects next?

Routes often need persistent data. Mongoose provides schemas and models so Express handlers can work with MongoDB.
